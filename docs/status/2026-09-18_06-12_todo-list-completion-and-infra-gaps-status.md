## e) WHAT WE SHOULD IMPROVE

1. **Artifact-before-claim.** Any "now have X" sentence in docs must be written in the same tool-chain as an existence/execution check of X (`test -x`, `ls`, a run). Harvest into docs-health VERIFY as a standing check: grep "now have"/"shipped" claims against the tree.
2. **File-claim protocol for parallel sessions.** Before creating a new file: `git log --oneline -1 -- <path> && git status --short <path>`. If either shows life, read theirs first. This session's near-clobber cost ~5 minutes and a confusing tool error.
3. **Single source for the coverage floor.** ci.yml (80%) and verify-dep-bump.sh (80%) will drift. Fix: the script greps the floor out of ci.yml (`grep -oE 't >= [0-9]+' .github/workflows/ci.yml`) so CI stays the single source.
4. **Gate hygiene rules.** (a) No ad-hoc compound validation one-liners in session work — explicit exit-code checks only. (b) Every gate must fail closed _and_ not lie: verify-dep-bump's fmt check needs daemon-awareness (retry-once).
5. **Registry-in-same-change rule.** New fuzz target ⇒ fuzz.yml + AGENTS.md updated in the same commit (exact analog of the UI-pins guard lesson that already bit this repo once).
6. **De-number rot-prone counts in AGENTS.md.** "Seven targets (see fuzz.yml)" → "the targets listed in fuzz.yml" — counts rot; pointers don't (same class as the FEATURES count drift, which at least has a guard).
7. **Rulesets-as-code.** `scripts/set-tag-protection.sh` (idempotent PUT of ruleset 23637848) so the rule survives repo mishaps and replicates fleet-wide; the three 422-discovered API quirks (target=tag, plain patterns, JSON-array exclude) are encoded nowhere but this session's memory.
8. **Bench smoke honest limits.** `-benchtime 1x` catches panics, not cliffs. Real regression detection needs benchstat baselines checked in per perf-relevant change (docs/research already holds the format).
9. **Demo-stack supply chain.** Pin prometheus/grafana images by digest + add dependabot config for `deploy/docker-compose.yml` so image bumps are proposed, not silent.
10. **Script env self-consistency.** verify-dep-bump.sh says "run OUTSIDE the devShell" but then needs `go` for `go tool cover` — either run the parse via `nix develop -c` too, or state the devShell requirement honestly.
